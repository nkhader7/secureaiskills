    Requirements
    Python 3.11+ and pyyaml are the only dependencies. tomllib ships with the stdlib.
    RequirementVersion
    Python3.11 or later
    pyyamlpip install pyyaml
    BrowserAny modern browser
    tomllibBundled with Python 3.11+
    Quick Start
    Clone, install, run benchmark, open dashboard.
    # 1. Clone the repository
git clone https://github.com/nkhader7/secureaiskills.git
cd secureaiskills

# 2. Install Python dependencies
pip install -r test-projects/skill-format-benchmark/requirements.txt

# 3. Navigate to the benchmark
cd test-projects/skill-format-benchmark

# 4. Run the benchmark (writes results/benchmark-results.json)
python benchmark.py

# 5. Serve the dashboard (opens browser automatically)
python serve.py

    Dashboard opens at http://localhost:8080  ·  Press Ctrl+C to stop

    Adding a New Skill
    Create variant files, a fixture directory, and register the skill in benchmark.py.
    # 1. Add 5 variant files in skill-variants/
your-skill.md  .yaml  .toml  .json  -inline.yaml

# 2. Create a fixture directory
mkdir ../skill-your-name-fixture/

# 3. Register in benchmark.py SKILLS list
{
  "skill_id": "your-skill-name",
  "fixture":  BENCH_DIR.parent / "skill-your-name-fixture",
  "variants": [
    ("md",          "your-skill.md",         parse_md),
    ("yaml",        "your-skill.yaml",        parse_yaml),
    ("toml",        "your-skill.toml",        parse_toml),
    ("json",        "your-skill.json",        parse_json),
    ("inline-yaml", "your-skill-inline.yaml", parse_inline_yaml),
  ],
},

# 4. Re-run
python benchmark.py && python serve.py
